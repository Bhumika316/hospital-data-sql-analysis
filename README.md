# 🏥 Hospital Data SQL Analysis

## 📌 Project Overview

This project focuses on analyzing hospital data using **PostgreSQL and SQL**.

The project contains 100 hospital records and covers analysis related to patients, doctors, departments, hospital stays, and medical expenses.

## 🛠️ Tools & Technologies

* PostgreSQL
* SQL
* pgAdmin
* CSV

## 📊 Analysis Performed

The project answers 10 SQL-based analytical questions:

1. Total number of patients across all hospitals
2. Average number of doctors per hospital
3. Top 3 departments with the highest number of patients
4. Hospital with the maximum medical expenses
5. Average medical expenses per day for each hospital
6. Longest hospital stay
7. Total patients treated per city
8. Average length of stay per department
9. Department with the lowest number of patients
10. Monthly medical expenses report
